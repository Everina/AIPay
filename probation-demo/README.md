## 打开

通过本地 HTTP 服务打开（3D 模型使用 ES modules 和 GLB 加载）。在此目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:8768/ 。草稿在 http://127.0.0.1:8768/storyboard.html 。

## 操作

滚动推进。整条螺旋倾斜 16° 并带有空间俯仰；当前卡片先来到中心转正，再放大；其阅读区间占每个节点滚动长度的约 30%，这段区间里卡片位置与大小保持稳定。停止滚动后不再移动，无计时自动切换。

点击前景卡片进入它的阅读位；底部左右箭头进入上一个或下一个节点。继续滚动会依次经历卡片汇聚、核心展开、成长、期待。末尾可重新播放。动效遵循系统减少动态效果偏好。主页面已移除 3D 模型、草稿分镜和简化动效三个辅助入口。

## 小海豹 3D 模型

- `dist/seal.html`：可拖动旋转、缩放的独立模型预览；提供正面、侧面、背面和网格视图。
- `dist/models/seal.glb`：实际 glTF 2.0 二进制模型，约 3.60 MB，14 个独立网格、148,516 个三角形；已改成翘臀姿态。
- `dist/models/coin.glb`：独立金币，约 298 KB，带贯穿菱形孔、倒角和两侧细边。
- `scripts/build_seal.py`：可重复生成海豹和金币两个模型的建模脚本，需要 NumPy。
- `dist/seal-scene.js`：模型预览和答辩转场共用的本地渲染器。
- `dist/references/seal-reference.png`：用户提供的原图，仅用于本地对照。

此模型为根据单张黑白线稿手工定义几何的圆润重建，背面、深度和乳白材质属于造型推演。身体为连续曲面，鳍和五官独立；没有骨骼绑定，不是为 3D 打印准备的单一实体。适合网页旋转展示和整体变换。海豹与金币作为两个独立对象加载。汇聚后金币独立抬起、旋转，两个模块卡片从金币附近展开；门户卡片及成长、期待的四张内容卡片统一使用香槟金。

Three.js 的 MIT 许可随包保存在 `dist/vendor/THREE-LICENSE.txt`。所有模型和渲染依赖均由本地服务加载，不会上传参考图片。

## 金币展开转场（v21）

两枚章节金币复用 `coin.glb`。成长金币先靠近内容区域，转为侧面，与发光金线交接；金线拉伸到卡片高度，两张卡片以中间边缘为轴错峰翻开，文字随后显现。期待金币在右上方缩小等候，再复用同一动作进入下一章。手机使用贯穿两张上下卡片的竖线展开。内容卡片保持简洁的香槟金样式，已回退大字、徽章与厚边框。

动作全部由滚动位置计算，无自动播放时间轴；向上滚动可逆向收回。已检查桌面 1280×720、手机 390×844、两章的展开中间帧与阅读停留、完整陈述开关及反向滚动状态一致性。减少动态效果偏好下取消卡片空间翻转与扫光。`dist/chapter-coins.js` 管理独立金币的角度、厚度和光照，`app.js` 管理位置及卡片衔接。
